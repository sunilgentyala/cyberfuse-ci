Overview

Enterprise vulnerability data arrives from sources that were never designed to communicate with each other. CVE records, STIX threat intelligence bundles, SIEM event logs, and source code repositories all describe security problems in different formats and schemas, with no unified way to correlate them.

CyberFuse-CI solves this by normalizing all four source types to a common entity schema, linking them through an LLM-augmented knowledge graph, and classifying each vulnerability using an adversarially hardened XGBoost ensemble. Every detection maps to a MITRE ATT&CK v15 technique with a corresponding remediation control, giving security teams actionable output rather than raw scores.

The result: a 6.2-day lead time on zero-day candidates before NVD publishes the corresponding CVE, with a 94.7% F1-score that holds at 91.2% under FGSM adversarial perturbation.

Key Contributions

🔌

Heterogeneous Data Fusion

Normalizes four incompatible source types (CVE/NVD, STIX 2.1, SIEM Syslog/CEF, CVEfixes) into a unified VulnerabilityEntity schema using source-specific normalization rules.

🌐

LLM-Augmented Knowledge Graph

BiLSTM-CRF named entity recognition, Graph Attention Network link prediction, and GPT-4 candidate link validation populate an OWL knowledge graph aligned with the MITRE ATT&CK data model.

🛡

Adversarially Hardened Classifier

XGBoost ensemble trained with FGSM perturbations at epsilon = 0.01 on 47-dimensional graph features. Holds 91.2% accuracy under adversarial attack versus 68.9-71.3% for baselines.

📈

6.2-Day Zero-Day Lead Time

Cross-source co-occurrence queries surface vulnerabilities a mean of 6.2 days before NVD publishes the CVE, giving security teams a critical pre-patch window.

🎯

MITRE ATT&CK v15 Mapping

FAISS semantic index over ATT&CK technique descriptions maps every detected entity to a technique ID, tactic, and linked mitigation control for downstream ticketing systems.

⚡

11.4 ms Inference Latency

GPT-4 link validation is an offline batch step during graph construction and adds zero overhead to the online inference path, which uses only the pre-built graph and XGBoost.

Experimental Results

Evaluated on the CVEfixes benchmark (10,077 vulnerable function samples across C, C++, Python, Java, JavaScript) and a 90-day anonymized enterprise SIEM corpus (2.3M log events). Five-fold stratified cross-validation. FGSM adversarial perturbation at epsilon = 0.01.

Repository Structure

connectors/

Layer 1 ingestion for NVD REST API v2.0, STIX 2.1/TAXII 2.1, Syslog/CEF normalizer, and CVEfixes SQLite loader. Defines the shared VulnerabilityEntity schema.

knowledge_graph/

OWL ontology-aligned graph builder, BiLSTM-CRF NER extractor with 150-term cybersecurity dictionary, GAT link predictor, and GPT-4 candidate link validator.

adversarial_training/

FGSM attack implementation, adversarial training harness with configurable epsilon sweep, and robustness evaluation reporter for clean vs. adversarial accuracy.

mitre_mapping/

FAISS IndexFlatIP over ATT&CK v15 technique descriptions encoded with all-MiniLM-L6-v2. Builds and queries the nearest-neighbor technique lookup index.

evaluation/

Reproducible benchmark scripts against CVEfixes with five-fold cross-validation. CSV outputs match Tables II and III in the companion paper.

tests/

Unit and integration tests for connectors, knowledge graph construction, adversarial training pipeline, and MITRE ATT&CK mapping.
